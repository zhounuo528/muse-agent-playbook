# 09 · 工具箱（实测小抄）

这一页不讲体系，只收**一条条实测好用的小招与免费工具**：每条写清干什么、怎么用、有什么坑。全部经过真实环境验证，不是看文档抄来的。连接器「有哪些、怎么连」看 CATALOG.md；这里收的是目录里不会写的使用技巧。

## 读取与抓取

### 1. X（推特）单帖免登录读取

- **干什么**：不用登录、不用开浏览器，拿到一条公开推文的全文、互动数据和媒体原链。
- **用法**：请求 `https://api.fxtwitter.com/status/<推文ID>`，返回 JSON：正文、作者、点赞/转发/浏览数、图片与视频直链（视频含 mp4 原档）。
- **坑**：备胎 `api.vxtwitter.com` 同样能读正文，但**没有浏览数、互动口径与主路不一致**，只作正文兜底，数字永远以主路为准、不要混比。官方 oEmbed 接口在很多网络环境下无响应，别在它身上耗时间。本招只读公开单帖；搜索、时间线、需登录内容不走它。

### 2. 微信公众号文章全文抓取

- **干什么**：公众号文章链接（mp.weixin.qq.com/s/…）用普通方式打开常被拦在「环境异常」验证页；真实浏览器又慢。
- **用法**：用 curl 伪装微信移动端 UA 直抓文章页：`-A "Mozilla/5.0 (iPhone; …) MicroMessenger/8.0.49 NetType/WIFI Language/zh_CN"`，返回完整服务端渲染 HTML，正文在 `id="js_content"` 区块，剥标签即得全文，秒出。
- **坑**：原理是文章页靠 UA 识别，移动微信 UA 不触发验证。只对文章页有效，公众号后台、视频号不适用。

### 3. Scrapling 抓反爬页面

- **干什么**：本地部署的抓取工具，自带浏览器指纹伪装，对付普通请求被拦的页面。
- **坑（通用）**：这类带自带证书库的抓取/HTTP 工具，在受限网络（企业代理、拦截型网关）里常报 `CERTIFICATE_VERIFY_FAILED`——不是目标站的问题，是它不认系统信任库。给进程设 `CURL_CA_BUNDLE` / `SSL_CERT_FILE` 指向系统证书库即可，别去怀疑站点或换工具。

## 免费数据 API（无 Key 或免费档，实测可用）

### 4. TheSportsDB（体育赛程比分）

- 免费档查球队、未来赛程、近期比分，够个人追踪一支球队用（赛前提醒、赛后战报的数据源）。

### 5. Frankfurter（汇率）

- 欧洲央行参考汇率，无 Key：最新/历史汇率与货币换算。适合订阅审计、外币价格折算这类「要准不要快」的场景。

### 6. Open Trivia DB（题库）

- 免费题库，按分类/难度取题，适合做问答互动、约战小游戏；题目是英文，交付前译一遍，只给题面不泄答案。

### 7. DailyHotApi（热榜聚合）

- 开源自部署，一个接口聚合 40 多个平台的热榜（微博、知乎、B站、抖音、百度、V2EX 等）。做每日资讯巡检的原料层很合适，免费、无 Key、只读。

### 8. 快递100 免费档（物流）

- 免 Key 查物流轨迹、自动识别快递公司，覆盖主流快递；适合「到哪了」类查询，不必逐家登录。

### 9. HowToCook（菜谱库）

- 开源菜谱数据集（300+ 菜）：按人数推荐搭配、按忌口排一周菜单并生成采购清单、查完整菜谱。「今天吃什么」这类问题直接出方案，不用现编。

## 避坑（每条都是一次真实教训）

### 10. 模型列表里有 ≠ 真能调

接任何模型服务，`/models` 列表里出现目标型号只说明「挂了牌」，不说明你的 Key 有权调用。**验收动作固定为：拿目标型号真发一次请求**，拿到真实回复才算可用。曾有四个新款型号全在列表里，逐个实测才确认可用范围——只看列表下结论，迟早翻车。

### 11. 装 Python 包先分清三类错

在虚拟机/受限网络里装包失败，先分诊再动手：

- **证书错**（CERTIFICATE_VERIFY_FAILED）：工具用自带证书库、不认系统 CA。pip/uv 加系统证书选项，或给解释器注入系统信任库构建的 SSLContext。
- **下载超时**：包源 CDN 在当前网络下不通，与包本身无关。换国内镜像（如清华 PyPI 镜像）通常立刻恢复；某个下载器（如 uv 的下载通道）在特定网关下就是下不动，别在它身上耗时间，换 pip。
- **代理明文应答**（SSL WRONG_VERSION_NUMBER）：流量没走代理、被透明网关用明文顶回来。检查工具是否读环境代理变量；有些工具只认自己的代理变量名，要单独给它设。
