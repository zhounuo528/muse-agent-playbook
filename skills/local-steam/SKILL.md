# Steam 公开接口查询（免 Key）【随仓附带】

## 用途
- 按名搜游戏拿 appid、查游戏新闻、当前在线人数、商店详情与指定区价格。
- 公开端点无需 API Key。涉及用户个人数据（游戏库、成就、库存）的端点需要 Key，不在本技能内——那类需求走你自己的 Steam API Key 接入（见 CATALOG A3 的 Steam 连接器条目，【配方】）。

## 工具
```bash
bin/steam --search "Baldur"          # 按名搜游戏
bin/steam --news 1086940 --count 5   # 游戏新闻（appid 示例）
bin/steam --players 1086940          # 当前在线人数
bin/steam --app 1086940              # 商店详情（含价格；脚本默认国区 cc=cn、简体中文）
```
换区价：改脚本里的 `cc`/`l` 参数即可（如 `cc=us&l=english`）。

## 使用规则
1. 商店 API 有限流（约 200 请求/5 分钟），新闻类结果缓存几小时再查，不要高频刷。
2. 新闻时间是 Unix 时间戳，展示时换算成用户时区。
3. 价格单位：商店搜索接口返回的是分，脚本输出已按原样标注；详情接口返回格式化价格字符串，直接引用。

## 愿望单降价监控（模式说明，未附工具）
「盯愿望单降价」的做法是：维护一份自己的愿望单清单（appid 列表）→ 定时用 `--app` 查现价与折扣 → 与上次价格比对 → 降幅达阈值才提醒，并对照一份「已推送日志」去重，同一游戏只推一次。作者自用的监控工具绑定了个人愿望单数据，未随仓附带；照这个模式用上面的查询命令即可自建。加监控前先核对用户是否已拥有该游戏，别把已入库的游戏报成降价喜讯。
