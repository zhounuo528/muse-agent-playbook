# TheSportsDB 体育数据（免费版）【随仓附带】

## 用途
查球队信息、未来赛程、近期比分（足球为主，也覆盖其他运动）。

## 连接信息
- 免费 V1 接口，无需注册、无需个人 Key：脚本使用官方文档公开的测试 key（路径段 `123`，这是官方文档化的公共测试值，不是任何人的密钥）。
- 限流约 30–100 请求/分钟；V1 没有完整直播比分（直播级数据在付费 V2，$9/月量级，走 `X-API-KEY` 请求头，本技能不接）。

## 工具
```bash
bin/sportsdb --team Liverpool        # 先按名查球队，拿到 idTeam
bin/sportsdb --next <idTeam>         # 该队未来赛程
bin/sportsdb --last <idTeam>         # 该队近期战绩
bin/sportsdb --nextleague 4328       # 联赛未来赛程（4328＝英超，4480＝欧冠，示例）
bin/sportsdb --lastleague 4328       # 联赛近期战绩
```

## 使用规则
1. 用户问球队、赛程、比分时用这个技能；先查 id 再查赛程，别凭记忆写 id。
2. 时间字段是 UTC，展示给用户时换算成其时区。
3. 空结果时接口返回 `"events": null` 而不是空数组，脚本已处理；你引用结果时也注意判空，别把 null 说成「没有比赛」之外的结论。
4. 不要高频刷接口。
