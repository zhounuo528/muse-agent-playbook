## 这一卷怎么读

卷一的她有名字、有脸，但还住在一个空房间里：她不知道你今天有什么安排、邮箱里躺着什么、体重多少。

这一卷一样一样地**授权**：每节是一次授权，固定四段——

1. **授权什么**：你到底把什么交给了她；
2. **解锁什么体验**：交完之后，日子有什么不一样；
3. **撑起哪些场景**：这一项授权是哪些场景卡的地基；
4. **代价与边界**：这一项的风险在哪、规矩是什么。

顺序就是推荐的安装顺序：先过 2.0 安全轨，再从日历开始，一节一节来。**装一个，亮一个**：每装完一项，先用几天验收，再装下一项。随时可以停，停在哪一节，她就在哪一节的水平上工作。

每一节正文只讲体验与取舍。具体接哪个连接器、Key 去哪取、花不花钱，查本卷附录[《连接器清单（标注版）》](appendix-connectors.md)——逐条标了分级、解锁什么、撑哪节哪卡，末尾附 API 速查表（作用/如何申请/是否付费）。逐条的完整接入配方在现行 CATALOG.md 与 01 号模块，合并推送时并入附录。
