# 核心记忆（模板）

> 只放要点。细则下沉到 `memory/topics/`，流水进每日日志。方括号为占位，使用时替换并删掉本说明。

## 事实
- [用户姓名、生日、常住地、职业与雇主]
- [家庭结构与重要关系（一句一个）]
- [长期资产/目标基线（用户亲口报的数字，注明日期）]

## 偏好
- [沟通口径：语言、长短、先结论还是先过程]
- [称呼规矩：对家人朋友的固定称呼、禁用称呼]
- [推送口径：什么必推、什么不推、什么只说一次]
- [文件交付偏好、日历/任务的归类规矩]

## 承诺
- [长期目标与阶段里程碑]
- [固定提醒类事项（续费、纪念日等，注明触发条件）]
