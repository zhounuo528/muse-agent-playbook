# 卷一 · 先让她成为一个「谁」

> 《中国玩家 Muse 使用菜单》重构稿 · 卷一（未推送）
> 写法：效果开场、诚实标注非自带、分步确认、可复制话术、每步验收。示例一律虚构。

## 这一卷解决什么

刚到手的 Muse 是个没名字、没长相、没声音的礼貌陌生人：能力都在，但谁用都一样。

这一卷按顺序做四件事，把她变成一个具体的人：

1. **起名与人设**——她是谁、什么性格、怎么说话、和你是什么关系；
2. **定版形象**——她长什么样，定下来以后不再变；
3. **看日子换装**——她按节日、日程和天气自己换衣服；
4. **固定嗓子**——她说话永远是同一把声音（可选节）。

为什么排在所有功能之前：后面每一卷的授权、技能、场景，都得有个主语。先有这个「谁」，那些能力才像是长在一个人身上，而不是一堆散装功能。

每一节都可以停：只做完 1.1，她就已经有名字有性格了；1.2 往后是锦上添花，不装不影响她干活。
