# 卷四 · 按日子过法查菜单

> 《中国玩家 Muse 使用菜单》重构稿 · 卷四（未推送）
> 本卷只做索引，不写正文：正文都在前三卷和场景卡里，这里只负责把路指对。

## 这一卷怎么用

- **新手别从这一卷开始装**：安装顺序在卷一到卷三，照着走不会乱。
- **这一卷是给「我只想先搞定某一块日子」的人用的**：比如你最近只想把财务理顺，就翻财务那一页，它会告诉你——要装哪几项授权（卷二）、要用哪几个机制（卷三）、对应哪几张场景卡，按什么顺序装最省事。

## 总览矩阵

| 维度 | 核心授权（卷二） | 核心机制（卷三） | 场景卡 |
|---|---|---|---|
| [生活](01-life.md) | 日历、邮件、提醒、位置 | 心跳巡检与睡眠门控 | 睡眠门控晨报、广告邮件清理、位置围栏、看日子换装（卷一 1.3） |
| [工作](02-work.md) | 日历、邮件、搜索与信息源 | 旁聊分工、外脑调度 | 会前小抄、发票接力（交叉财务） |
| [出行](03-travel.md) | 出行服务、位置、日历 | 心跳巡检 | 票务自动建历、明日出行电量检查 |
| [健康](04-health.md) | 健康数据 | 睡眠门控（交叉） | 健康周月报合成 |
| [娱乐](05-entertainment.md) | 内容与娱乐、搜索与信息源 | 每周复盘里的口味修正 | 每日精选雷达、观赛管家 |
| [财务](06-finance.md) | 邮件（财务分诊） | 知识库双写与月结 | 订阅全景、发票发现与归档接力、费用监控与月结接力 |

每页的结构都一样：这个维度装好是什么样 → 最小可用组合（先装这几样就有体感）→ 进阶组合 → 全部条目清单。
