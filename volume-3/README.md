## 这一卷解决什么

卷二装完，她「够得着」你的世界了，但还是你推一下她动一下。这一卷装的是**运转和增长**：

- 前五节是运转机制——记忆让她记得住事，巡检让她自己值班，旁聊让她干活不刷屏，外脑让她会调度帮手，双写与月结让产出有归宿；
- 中间两节是增长机制——新本事按什么流程进来、每周怎么复盘更新这份菜单；
- 3.8 是联动总则——所有数据怎么焊在一起用，是全仓的灵魂；
- 3.9 讲助理间派单协作——当她有一个「本地执行手」时，派单、回执、熔断的规矩；
- 3.10 是主动消息机制——她先开口时的类型、频率与分寸纪律；3.11 是决策账——你拍的板记下来、到期回访；
- 卷末附录[《GitHub 项目与技能清单》](appendix-projects-skills.md)：哪些开源项目带来能力、哪些添乐趣，逐个写清作用与接入法。

顺序建议：先 3.1 记忆（所有机制的地基），再 3.2 巡检，其余按需装。这一卷不要求一次装完，它是她接下来几个月慢慢长出来的部分。
