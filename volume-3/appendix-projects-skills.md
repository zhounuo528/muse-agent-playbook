# 卷三附录 · GitHub 项目与技能清单

> 本附录回答两个问题：**哪些开源项目值得装**（各带来什么能力、添什么乐趣），**仓里这些技能各是干什么的**。
> 口径：项目全部为开源免费；「免费」指软件本身不要钱，自备部署环境（服务器/常开机器）和它依赖的 API Key 另算，API 的费用见卷二附录速查表。
> 装任何一个之前，先走 [3.6 的流程](../volume-3/06-growing-new-abilities.md)：评估 → 代码审计（第三方脚本先看再跑）→ 小样验证 → 跑通一周再立卡。

## 四、观望与否决：清单在哪、规矩是什么

- **观望**：官方存在、路径经公开文档核实、但未实测接通的条目在 [OBSERVED.md](../OBSERVED.md)，只供选型，启用前重走验证。
- **否决留因**：评估后决定不装的项目，在评估记录里留一行——项目名＋一句否决原因＋日期。否决不是删除：留着这一行，下次雷达再扫到它，谁都不会重复评估一遍。原因写事实（成本、折腾度、与已有能力重复、风险），不写情绪。
